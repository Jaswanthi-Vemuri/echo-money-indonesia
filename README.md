# Echo Money — "Now Live in Indonesia" (15s vertical ad)

A single, self-contained **1080×1920 (9:16)**, **exactly 15-second** animated advertisement
built as pure HTML/CSS/SVG/JS. No libraries, no fonts, no external assets — it runs offline
in any modern browser.

**Live:** https://jaswanthi-vemuri.github.io/echo-money-indonesia/
**Clean (no dev HUD):** https://jaswanthi-vemuri.github.io/echo-money-indonesia/?clean=1

## The 15-second structure

| Time | Scene | Copy |
|------|-------|------|
| 0–3s   | Hook — Indonesia outline + pulse + travelling line | **INDONESIA, YOU'RE CONNECTED.** |
| 3–6s   | Global reach — flat world node-network            | **110+ COUNTRIES** |
| 6–9.5s | Local methods — nodes morph into payment cards    | **210+ LOCAL PAYMENT METHODS** |
| 9.5–12s| Benefit — bidirectional pulses along the links    | **REAL-TIME PAYMENTS & PAYOUTS — TO AND FROM INDONESIA** |
| 12–15s | Announcement — network converges, final reveal    | **ECHO MONEY — NOW LIVE IN INDONESIA** |

## Notes
- The `echo money` logo in Scene 5 is a **labeled placeholder** — replace it with the authentic logo during editing.
- URL params: `?clean=1` hides the dev HUD for recording; `?t=7000` freezes a single frame at 7000 ms.
- To export MP4: open with `?clean=1` and screen-record, or drive `render(t)` headlessly frame-by-frame.
